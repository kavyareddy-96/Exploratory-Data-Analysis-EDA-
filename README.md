Exploratory Data Analysis (EDA)

This task involves performing EDA on the Titanic dataset using Python.

The objective is to extract insights using statistical summaries and visualizations.

The dataset contains passenger details like age, gender, class, fare, and survival status.

Python libraries used: Pandas, Matplotlib, Seaborn.

Steps followed:

Loaded and explored the dataset structure.

Checked for null values and data types.

Performed univariate analysis on individual columns.

Conducted bivariate and multivariate analysis to identify relationships.

Used plots like bar charts, histograms, boxplots, heatmaps, and pairplots.

Filled missing values where necessary.

Wrote observations below each visual.

Key findings:

Females had a higher survival rate than males.

1st class passengers were more likely to survive.

Higher fares correlated with better survival chances.

Most deaths occurred among 3rd class male passengers.

Younger passengers had better chances of survival.
